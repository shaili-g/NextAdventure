# Application Facts

Standing answers for job application forms. Read by `application-answers`. Leave a row as [ask me] to be asked each time.

| Field | Answer |
|---|---|
| Legally authorized to work in [country]? | [Yes / No] |
| Will you now or in the future need visa sponsorship? | [Yes / No] |
| Earliest start date or notice period | [e.g., "Two weeks from offer"] |
| Willing to relocate? To where? | [ ] |
| In-office days you can commit to | [ ] |
| Salary expectations (default answer) | [a range, "Open, depending on the role", or [ask me]] |
| How did you hear about us? (default) | [e.g., "Company careers page"; the real source is used when known] |
| Demographic and voluntary self-identification questions | [your answer, "Decline to answer", or "I'll answer these myself"] |
| Pronouns (if asked) | [optional] |
| OK to contact current or former employers? | [Yes / No / "After an offer"] |
